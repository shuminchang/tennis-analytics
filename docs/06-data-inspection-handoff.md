## 球員身分疑點

球員 ID 轉整數後，ATP/WTA 各自均無碰撞，仍須使用 (tour, player_id)。
名稱規則只是找出候選，不是可靠的真人身分識別。

| 檢查 | ATP 比賽數 | WTA 比賽數 |
| --- | ---: | ---: |
| 主檔有效生日晚於賽事日期 | 141 | 24 |
| 明確占位名稱出現在比賽 | 90 | 0 |
| 含 unknown 的部分姓名 | 15 | 0 |
| 勝敗方 ID 相同 | 3 | 1 |
| 上述疑點聯集 | 246 | 25 |

原因可能重疊，不能直接相加。ATP 同 ID 的 3 場包含在占位名稱 90 場中。
ATP 246 場範圍均為 INCLUDE；WTA 24 場生日疑點為 REVIEW，另一場同 ID 為 INCLUDE。
ATP 生日疑點涉及 26 個 ID，WTA 涉及 5 個 ID。
例如 ATP 101495 主檔 Miguel Tobon / 2006-06-19 涉及 44 場；
這只能證明對照矛盾，不能判定是哪個來源欄位錯誤或逕自改成同名長輩。

ATP 主檔名稱候選 99 個、WTA 2 個，不代表全部參加本次比賽。
ATP 199999 / U Unknown 有 93 次勝敗方角色出現、涉及 90 場；不可將其視為同一真實球員。
WTA 200000 / X X 與 252411 / Ann Unknown Portland 在本次年度比賽中皆未出現。
有部分姓名的 unknown 候選不可直接當成共用占位 ID 刪除。

先前 WTA 非正年齡 26 場與本次生日晚於賽事 24 場並不矛盾：
其餘兩場為 1971 檔第 360、376 筆，球員 200535，日期 19710125，年齡原值 0.0；
主檔生日 1971-01-13 早於該日期，但數值仍不適合直接作年齡分析。
ATP 來源年齡非正值為零，也不能證明主檔身分對應正確。

### 品質處理設計，尚未實作

- 明確占位 ID、勝敗同 ID、生日時間矛盾保留原始列與疑點，先不進入預設個人勝負、H2H 或 Elo。
- 身分矛盾以受影響比賽為單位待查，不自動抹除該球員全部生涯，也不自行配對同名球員。
- 部分姓名包含 unknown 只記錄待查標記，不憑名稱規則自動判定身分錯誤。
- 其他缺值與數值異常沿用 01/04 文件的指標層級排除，不能一概隔離整場。
- 賽事 INCLUDE/EXCLUDE/REVIEW 與身分品質狀態分開；未計算套用全部品質規則後的總筆數。
