### 6.2 Compose 設定

```bash
nano compose.yaml
```

```yaml
services:
  db:
    image: postgres:16-bookworm
    environment:
      POSTGRES_DB: ${POSTGRES_DB:?Set POSTGRES_DB in .env}
      POSTGRES_USER: ${POSTGRES_USER:?Set POSTGRES_USER in .env}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:?Set POSTGRES_PASSWORD in .env}
    ports:
      - "127.0.0.1:${POSTGRES_PORT:-5433}:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", 'pg_isready -U "$$POSTGRES_USER" -d "$$POSTGRES_DB"']
      interval: 5s
      timeout: 5s
      retries: 10
      start_period: 10s

volumes:
  postgres_data:
```

- 主機 5433 轉到容器 5432，避免與本機既有資料庫衝突。
- 127.0.0.1 是本機連線入口。
- 具名 volume 保存資料，但不是備份。
- `${VAR:?message}` 在必要值缺少時報錯；healthcheck 的 `$$` 讓變數留給容器 shell 展開。
- postgres:16-bookworm 固定主版本與系統系列，不是不可變的映像鎖定。
- POSTGRES_USER 建立的是初始化管理員；應用專用低權限帳號尚待建立。

```bash

git check-ignore .env
git status --short
```

`--quiet` 檢查設定而不印出含密碼的完整設定。`git check-ignore` 預期顯示 `.env`。

### 8.2 自動化 HTTP 測試

```bash
mkdir -p src/test/java/com/shuminapp/tennis/health
nano src/test/java/com/shuminapp/tennis/health/HealthControllerTest.java
```

以下為修正後可通過的完整測試：

```java
package com.shuminapp.tennis.health;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.test.web.client.TestRestTemplate;
import org.springframework.http.MediaType;

import static org.assertj.core.api.Assertions.assertThat;

@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class HealthControllerTest {

    @Autowired
    private TestRestTemplate restTemplate;

    @Test
    void healthEndpointReturnsUp() {
        var response = restTemplate.getForEntity(
                "/v1/health",
                HealthController.HealthResponse.class
        );

        assertThat(response.getStatusCode().value()).isEqualTo(200);
        assertThat(response.getHeaders().getContentType())
                .isNotNull()
                .satisfies(contentType ->
                        assertThat(contentType.isCompatibleWith(MediaType.APPLICATION_JSON))
                                .isTrue());
        assertThat(response.getBody())
                .isEqualTo(new HealthController.HealthResponse("UP"));
    }
}
```

```bash
./mvnw test
```
