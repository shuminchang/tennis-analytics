## 第一版轉換規則

- 由來源目錄補上 tour：ATP 或 WTA。
- 球員主鍵使用 (tour, player_id)，不以姓名識別。
- 空白生日與身高轉為 NULL，不補成 0。
- 生日必須是八位 ASCII 數字，且可解析為有效日期。
- 非空但無效的生日轉為 NULL，另外記錄來源檔案、
  球員 ID、原始值與原因，不猜測缺漏的月或日。
- 空白 hand 轉為 NULL；其他代碼保留原值。
- 特殊姓名與疑似佔位紀錄先保留，後續查核。
- 統計排除所需欄位缺值的紀錄，並揭露有效樣本數。

### 設計決定

- 保留 matches.id 作為內部主鍵。
- 來源唯一限制改為 (tour, tourney_id, round, match_num)。
- round 設為 NOT NULL，匯入時拒絕空白鍵值。
- tourney_level 使用 text，支援 PM、T1、50+H 等代碼。
- WTA 舊鍵衝突的 16 組紀錄內容與輪次不同，不可直接去重。
- 未來更新仍需檢查唯一鍵；相同鍵但內容改變時，
  必須辨識為來源修訂或衝突，不可一律靜默覆蓋。
- 保留來源快照、相對檔名與 CSV 紀錄序號供追查。
  紀錄序號只用於定位來源，不作為跨快照的比賽識別碼。
